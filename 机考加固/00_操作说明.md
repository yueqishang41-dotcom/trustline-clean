# 机考加固 — Windows 级锁定操作说明

> 目标：被试在测验中**无法切到其他页面/程序**（Alt+Tab、Win 键、开始菜单、切换用户等全部堵死）。
> 网页锁（kiosk.js）只管浏览器内部；Alt+Tab / Win 键 / Ctrl+Alt+Del 是**操作系统级**的，浏览器拦不住，必须到 Windows 层面加固。

---

## 一、为什么还需要这一步

| 路径 | 网页锁能挡吗 | 说明 |
|---|---|---|
| Esc / F11 退全屏、F12、Ctrl+W 等 | ✅ 能 | kiosk.js 已拦截 |
| **Alt+Tab** | ❌ 拦不住 | OS 级，浏览器收不到按键事件 |
| **Win 键 / Win+Tab / Win+D 等** | ❌ 拦不住 | OS 级 |
| **Ctrl+Alt+Del**（安全界面） | ❌ 拦不住 | Windows 硬安全界面 |
| 物理电源键 / 拔线 | ❌ 拦不住 | 物理手段 |

本文件夹的脚本就是来堵这些 OS 级路径的。

---

## 二、正式实验推荐配置（按顺序做一遍）

### 第 0 步：建一个"被试专用"本地账户
1. 设置 → 账户 → 其他用户 → 添加账户 → **不使用 Microsoft 账户** → 创建本地账户（如用户名 `ks`，密码简单即可）。
2. 以后每次施测都**用这个账户登录**电脑，测完登出。好处：加固注册表只作用于该账户，不污染主试自己的账户；被试切不出该账户环境。

### 第 1 步：运行加固注册表
- 双击 `01_禁AltTab等切换.reg`（改当前用户，**无需管理员**）。
- 右键 `02_隐藏切换用户与锁定.reg` → **以管理员身份运行**（隐藏 Ctrl+Alt+Del 界面的"锁定/切换用户"，并禁用任务管理器）。
- **注销重新登录**一次，使 Alt+Tab 禁用生效。
- ⚠️ Win10/11 个别版本 `CoolSwitch` 可能不生效，**务必实测**（见第三节清单）；不生效就靠第 3 步的 AHK。

### 第 2 步：用机考模式打开测验
- 双击仓库根目录的 `启动正式测验_机考模式.bat`（Edge 全屏 kiosk，无地址栏/标签栏/关闭按钮）。

### 第 3 步（可选但推荐）：屏蔽 Win 键
- 在专用账户里安装 **AutoHotkey**（免费），双击 `04_禁用Win键_防切屏.ahk`。可放入该账户"启动"文件夹实现开机自启。
- 堵住 Win 键、Win+Tab/D/L/E/R/A/S、Alt+Esc、Ctrl+Esc。

### 第 4 步：物理设置（堵最后两个洞）
- 电源按钮设为"不采取任何操作"（控制面板 → 电源选项），**合上盖子**设"不采取任何操作"，禁用睡眠（防睡着后唤醒弹锁屏）。
- 提醒被试手机放门外/交上来（**用另一台设备查资料，任何软件都拦不住，只能靠规则**）。

---

## 三、施测前 1 分钟自测清单（主试自己跑一遍）

1. 登录专用账户 → 双击 bat → 全屏进入测验首页 ✅
2. 按 `Alt+Tab` → **切不出去**（或切出又被网页锁警告+日志）✅
3. 按 `Win` 键 / `Win+D` → 无反应 ✅
4. 按 `Ctrl+Alt+Del` → 只见"关机/注销"类选项，无"锁定/切换用户"，且任务管理器打不开 ✅
5. 被试进入答题、点"开始工作"全屏锁定后 → 主试离开 ✅

---

## 四、结束 / 复原电脑

- 被试做完全部实验、数据导出确认无误后：
  - 退出 AHK（右下角托盘图标）。
  - 双击 `03_还原默认.reg`（管理员权限）恢复所有注册表。
- 专用账户可以留着下轮继续用，也可以删除。

---

## 五、诚实边界（写报告时要有数）

- **Ctrl+Alt+Del 安全界面本身无法被软件隐藏或拦截**（Windows 硬特性），我们只能隐藏其中的"锁定/切换用户"、禁用任务管理器；若被试在该界面选"注销/关机"，本次会话会被打断——但**数据不会丢**（本机已备份 + 下次打开自动补传），且会被网页锁记为离开（`page_blur`）。
- **物理断电/拔网**：任何软件都拦不住，靠房间规则与门禁。
- 商业考试系统用的是"专机专管 + 摄像头监考"；在普通 Windows 家用版（Home）上，本方案已是软件层面能做到的最强。

### 若实验室是 Windows 专业版/教育版（Pro/Edu）
还有系统自带的终极方案：**设置 → 账户 → 其他用户 → 设置为 Kiosk（Assigned Access）**，把 Microsoft Edge 指定为 Kiosk 应用并填入测验网址。该模式是微软官方一体化的锁定环境，比上面的手动注册表更干净。Home 版没有此功能，故本方案以注册表+AHK 替代。
